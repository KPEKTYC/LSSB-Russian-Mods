# LSSB · Русский перевод и моды

Русский интерфейс, сюжет и диалоги для **Love & Sex: Second Base** —
с дополнительными улучшениями карты и встроенным управлением модами.

**[Скачать](https://github.com/KPEKTYC/LSSB-Russian-Mods/releases/tag/v1.87.0-own)**
· **[Как установить](docs/INSTALL_RU.md)**
· **[Только русификатор](docs/INSTALL_RU.md#только-локализация)**

![Пример русского текста в игре](docs/images/russian-dialogue.png)

## Выберите нужные компоненты

| Компонент | Что даёт |
| --- | --- |
| **Русская локализация** · 1.87.0 | Перевод интерфейса, сюжетных реплик, диалогов и игровых сообщений |
| **Мод-менеджер** · 1.4.0 | Управление нашими и подключёнными сторонними модами в игре |
| **Карта и интерфейс** · 1.5.2 | Улучшенное отображение и исправление карты в программном рендерере |
| **Быстрый запуск** · [1.2.0](https://github.com/KPEKTYC/LSSB-Russian-Mods/releases/tag/startup-v1.2.0-own) | Ускорение подготовки изображений при запуске |

Быстрый запуск 1.2.0 доступен отдельным обновлением.
[Результаты измерений и границы проверки](docs/STARTUP_1.2.0.md):
выигрыш повторного запуска на стенде — около 0,3 секунды.

**Русификатор устанавливается в чистую игру одним файлом.** Все необходимые
файлы перевода уже включены; мод-менеджер и другие моды необязательны.
Скачайте **[LSSB_Rusifikator_1.87.0.zip](https://github.com/KPEKTYC/LSSB-Russian-Mods/releases/download/v1.87.0-own/LSSB_Rusifikator_1.87.0.zip)**
и скопируйте RPA из папки `game` архива в папку `game` установленной игры.

[Обновление старого перевода и подробная инструкция →](docs/INSTALL_RU.md)

В переводе есть нейтрально адаптированные фрагменты —
[об изменениях текста](docs/INSTALL_RU.md#об-адаптации-текста).

Менеджер **1.4.0** автоматически распознаёт обновления перевода, карты/интерфейса
и быстрого запуска. Для сторонних модов предусмотрено подключение через
описание автора. [Обновление модов](docs/INSTALL_RU.md#обновления-модов-с-менеджером)
· [Для авторов модов](docs/AUTHOR_MODS_RU.md)

[Скачать только менеджер 1.4.0](https://github.com/KPEKTYC/LSSB-Russian-Mods/releases/download/v1.87.0-own/LSSB_Mod_Manager_1.4.0.zip)
можно отдельно: перевод и остальные наши моды для него необязательны.

## Управление в игре

![Мод-менеджер LSSB](docs/images/mod-manager.png)

Кнопка **«Моды»** открывает список установленных компонентов. Выберите нужные,
нажмите **«Применить и выйти»** и запустите игру снова.

## Совместимость

Проверено с **LSSB 26.9.0e** и **Ren'Py 8.5.3.26051504**.
Смена номера версии не отключает моды автоматически; изменения самой игры
могут потребовать обновления. Для минимального набора используйте
[только локализацию](docs/INSTALL_RU.md#только-локализация).

Моды устанавливаются отдельными файлами. Перед обновлением сохраните предыдущие
версии — [инструкция включает откат и удаление](docs/INSTALL_RU.md#откат-и-удаление).
