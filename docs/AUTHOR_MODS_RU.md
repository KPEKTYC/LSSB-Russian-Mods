# Подключение своего мода

[← На главную](../README.md) · [Установка](INSTALL_RU.md)

Менеджер **1.4.0** поддерживает моды других авторов. Пересобирать менеджер,
добавлять мод в его исходный каталог или получать наш ключ подписи не нужно.
Мод остаётся обычным архивом Ren’Py RPA-3.0 и может работать без менеджера.
Текущие условия для нового оригинального кода — [бесплатное некоммерческое
использование](../LICENSE_SCOPE.md) с сохранением авторства KPEKTYC.
Добровольные пожертвования допустимы без платных функций или доступа.
У собственного мода автора может быть другая лицензия; подключение к
менеджеру её не меняет. Ранее выданные MIT/CC BY разрешения описаны отдельно.

## Подготовка выпуска

1. Выберите постоянный идентификатор: от 1 до 48 строчных латинских букв,
   цифр и знаков `_`, например `weather`.
2. Соберите мод в `zz_mod_weather.rpa`. Пространство имён `zz_mod_` позволяет
   подключать только явно подготовленные моды и не затрагивать оригинальные архивы.
   Проверьте порядок загрузки своего архива относительно остальных модов.
3. Создайте описание командой из корня этого репозитория:

```powershell
python tools/register_mod.py --archive "путь/zz_mod_weather.rpa" --id weather --name "Погода" --version 1.0.0 --description "Дополнительная погода"
```

Команда создаст рядом `zz_mod_weather.lssb-mod.json`. Распространяйте **оба
файла вместе**. Пользователь кладёт их в `game`, устанавливает менеджер
1.4.0 или новее и открывает кнопку «Моды». Если игра была запущена, её нужно
перезапустить, чтобы загрузить код нового мода.

Описание имеет следующий формат; вместо примера контрольной суммы команда
запишет настоящий SHA-256 **всего** RPA:

```json
{
  "schema": 1,
  "id": "weather",
  "filename": "zz_mod_weather.rpa",
  "name": "Погода",
  "description": "Дополнительная погода",
  "version": "1.0.0",
  "sha256": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
}
```

Версия имеет вид `1.2.3` или `1.2.3-beta.1`. Название — до 64 символов,
описание — до 160; разметка Ren’Py, квадратные скобки и управляющие символы
не допускаются. JSON — UTF-8 без BOM, до 8192 байт. Дополнительные и
повторяющиеся поля не допускаются. Менеджер поддерживает до 64 внешних описаний.

## Обновления

Сохраняйте идентификатор и имя архива. После сборки новой версии повторите
команду с новым номером и распространите новый RPA вместе с обновлённым JSON.
При закрытой игре пользователь заменяет оба файла. Менеджер сам прочитает
новую версию; его собственный архив менять не нужно.

Если мод отключён, пользователь заменяет `zz_mod_weather.rpa.disabled`,
сохраняя это окончание. JSON остаётся `zz_mod_weather.lssb-mod.json` и всегда
содержит обычное имя `zz_mod_weather.rpa`. Не оставляйте обе копии архива.
При удалении мода перенесите его RPA, вариант `.disabled` и JSON вне игры.

Описание подтверждает соответствие архива данным, установленным пользователем;
оно **не является подписью автора**. Скачивайте моды из доверенного источника.
Менеджер не выполняет код и не читает pickle-индекс RPA для распознавания.
Как и любой установленный мод, включённый архив загружается самой игрой при запуске.

У наших трёх модов остаётся отдельная проверка подписи издателя. Внешнее
описание не может подменить их, менеджер или оригинальные архивы игры.
Повреждённые описания, несовпадение хеша, две копии одного архива и прерванные
операции требуют исправления. Если архив обновили после выбора действия,
сначала отмените прежний выбор и выберите его заново.

Распознавание новой версии не подтверждает её совместимость с изменившимся
кодом игры или другими модами: это проверяет автор мода.
