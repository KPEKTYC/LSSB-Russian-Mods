# Установка русификатора LSSB

[← На главную](../README.md)

## Только локализация

1. Скачайте **`LSSB_Russian_1.88.2.zip`** со [страницы выпуска](https://github.com/KPEKTYC/LSSB-Russian-Mods/releases/tag/v1.88.2-own).
2. Закройте игру. В Steam откройте её свойства → «Установленные файлы» → «Обзор».
3. Из скачанного ZIP скопируйте файл `game/zzzzzz_lssb_localization_ru.rpa`
   в папку `game` рядом с `LoSeSb.exe`.
4. Запустите игру — русский язык включается самим русификатором.

Пример правильного расположения:

```text
Love & Sex Second Base/
├── LoSeSb.exe
└── game/
    ├── scripts.rpa
    ├── …
    └── zzzzzz_lssb_localization_ru.rpa
```

Русификатор работает самостоятельно в чистой игре. Базовые русские строки, исправления
и настройка языка уже внутри. **Мод-менеджер, другие моды, GamePatchAnalyzer
и отдельно скачиваемые файлы перевода не нужны.**

Не создавайте вложенную папку `game/game`. Кнопка **Code → Download ZIP** на GitHub
скачивает исходники проекта, а не готовый русификатор.

## Если перевод уже был установлен

В обновлении **1.88.2** исправлены переводы навыков, встреч и работы в телефоне.
Если предыдущий комплект уже установлен, достаточно заменить только архив русификатора.
Начинать новую игру или удалять сохранения не требуется.

Перед заменой сохраните старые файлы в резервную папку **вне папки игры**:

- `game/zzzzzz_lssb_localization_ru.rpa` и его вариант `.rpa.disabled`, если есть;
- `game/tl/russian/gamepatchanalyzer.rpy` и `gamepatchanalyzer.rpyc`, если есть;
- `game/gamepatchanalyzer_language.rpy` и `gamepatchanalyzer_language.rpyc`, если есть.

Затем установите новый RPA по инструкции выше. Старый свободно лежащий файл
перевода имеет приоритет над одноимённым файлом внутри архива, поэтому его
нужно убрать из игры при переходе на самостоятельную сборку.
Файл `.gpa.jsonl` относится к редактору и игре не требуется; его можно сохранить
с резервной копией. Не переносите всю папку `tl`: в ней могут быть другие языки.

Если нужен только русский язык, также уберите в резервную папку остальные
наши архивы из таблицы ниже и их варианты `.disabled`.

## Дополнительные моды

Для полного комплекта скачайте **`LSSB_Mods_1.88.2_Lively_HD_2026-10-28.zip`** из того же выпуска.
Он содержит самостоятельный русификатор и три необязательных компонента.
Можно скопировать только нужные файлы.

| Файл в папке `game` | Компонент |
| --- | --- |
| `zzzzzz_lssb_localization_ru.rpa` | Русификатор 1.88.2 — единственный обязательный файл для русского языка |
| `zzzzzzzz_lssb_mod_manager.rpa` | Мод-менеджер 1.4.1 |
| `zzzzz_lssb_visual_quality.rpa` | Фоны HD, персонажи Lively, карта и интерфейс 1.7.0 |
| `zzzzzzz_lssb_startup_fast.rpa` | Быстрый запуск 1.2.0 |

Для первого перехода со старого менеджера используйте менеджер **1.4.1** и
совместимый комплект дополнительных модов. Кнопка **«Моды»** в главном меню
позволяет выбрать компоненты. Нажмите **«Применить и выйти»** и запустите игру
заново. Отсутствующие моды менеджер не скачивает.

HD-фоны включаются автоматически при размере окна выше 1280×720. Во время фоновой проверки файлов меню «Моды» уже открыто, но переключатели временно недоступны.

### Обновления модов с менеджером

Один раз установите менеджер **1.4.1** из текущего комплекта. Затем можно
обновлять каждый мод отдельно при закрытой игре, сохраняя предыдущий файл
вне папки игры. Менеджер сам определит версию нового архива.

Автоматическое распознавание наших выпусков доступно для:

- русификатора **1.86.0 и новее**;
- карты и интерфейса **1.5.2 и новее**;
- быстрого запуска **1.1.1 и новее**.

При обновлении заменяйте только RPA нужного компонента. Если он отключён,
заменяйте его файл с окончанием `.rpa.disabled`, предварительно дав новому
архиву то же имя. Не оставляйте одновременно `.rpa` и `.rpa.disabled`.
Состояние останется отключённым. Пересобирать или заменять менеджер при
следующих выпусках этих модов не нужно.

Технические подробности проверки файлов — в [документации разработчика](DEVELOPMENT.md).

### Моды других авторов

Если нужен только менеджер, возьмите `game/zzzzzzzz_lssb_mod_manager.rpa`
из единого комплекта и скопируйте его в папку `game` установленной игры. Локализация, карта и быстрый запуск для него не обязательны.

Менеджер 1.4.1 обнаруживает архивы вида `zz_mod_<id>.rpa`, если автор
прилагает соответствующий файл `zz_mod_<id>.lssb-mod.json`. Скопируйте оба
файла в `game`. При обновлении заменяйте и архив, и JSON; для отключённого
мода сохраняйте окончание `.rpa.disabled`, имя JSON не меняйте.

Сторонние моды в наш комплект не включены. Существующие архивы без описания
автора автоматически в список не добавляются. Не переименовывайте чужие моды
произвольно: порядок загрузки может иметь значение.
[Инструкция и инструмент для авторов →](AUTHOR_MODS_RU.md)

Не переименовывайте файлы RPA: их имена нужны для правильной загрузки.

## Совместимость и объём перевода

Проверенная версия: **LSSB 26.9.0e / Ren’Py 8.5.3.26051504, Windows**.
Проверки включают локализацию отдельно без старых файлов перевода и полный
комплект наших модов. Номер версии игры сам по себе не отключает моды;
изменения кода и экранов могут потребовать обновления.

Пакет содержит все необходимые файлы для установки. Проверка диалоговых узлов
не обнаружила пропусков, но это не гарантия перевода каждого динамического
сообщения игры. Некоторые названия и пользовательские имена сохраняются
намеренно. Полного прохождения всех сюжетов не выполнялось.
Подробности проверок — в [технической документации](DEVELOPMENT.md).

### Об адаптации текста

В версии 1.88.0 одна реплика Cupid (`cupid_angela_bruce_event_04_d6607cbc`)
передана нейтрально. Возраст персонажей, игровые действия и развилки сохранены.

В выпуске 1.85.0 обработаны последние 66 отложенных реплик: 23 переведены
точно, 43 переданы в неэротической адаптации. Ещё одна соседняя реплика
адаптирована для последовательности сцены. Сохранены исходный возраст,
участники и сюжетная роль событий; игровые действия и развилки не изменены.
Адаптация убирает сексуализацию детских воспоминаний и подробности насилия,
сохраняя их неэротическое описание там, где оно необходимо для сюжета.

Сторонняя википедия **Daerty** не входит в комплект и не переводится.

## Откат и удаление

Закройте игру и перенесите выбранный RPA нашего мода и его вариант `.disabled`,
если есть, в резервную папку вне игры. Для отката верните прежний архив,
его прежние дополнительные файлы перевода и соответствующий менеджер.

Не удаляйте `scripts.rpa`, `bg.rpa`, `interface.rpa`, другие оригинальные архивы,
сохранения или всю папку `tl`. Для чистой установки 1.88.2 удаление единственного
RPA русификатора убирает и базовый перевод, и настройку русского языка.

Для самостоятельной сборки см. [документацию разработчика](DEVELOPMENT.md).
